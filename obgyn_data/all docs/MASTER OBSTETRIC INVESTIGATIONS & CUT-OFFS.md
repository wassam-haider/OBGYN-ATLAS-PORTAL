One important terminology rule

For your final MRCOG/FCPS notes, I recommend using:

FLI = First-line investigation
IOC = Investigation of choice
GS = Gold standard/definitive test

and writing “No true gold standard” whenever the diagnosis is fundamentally clinical—for example placental abruption, shoulder dystocia, cord prolapse, chorioamnionitis and postpartum endometritis. This prevents the common exam error of calling an ultrasound or blood test a “gold standard” when it actually is not.

The MRCOG/FCPS rule

Use:

centiles → fetal growth
MoM → MCA/biochemical screening
assay-specific thresholds → biomarkers
gestational-age-specific ranges → maternal/fetal laboratory values
clinical criteria → abruption, shoulder dystocia, cord prolapse, chorioamnionitis
serial measurements → β-hCG, bile acids, antibody levels, fetal growth
imaging criteria → placenta, fetal anatomy, ectopic pregnancy
physiology + quantified blood loss → PPH

This gives you the consolidated framework of condition → first-line investigation → IOC → true gold standard/definitive test → normal → abnormal → diagnostic threshold → severe threshold → interpretation, rather than simply listing investigations.
