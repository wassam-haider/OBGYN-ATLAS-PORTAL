⭐ MRCOG EMERGENCY MASTER ALGORITHM

For every case, answer in this order:

1. TRIAGE

ABCDE → stable/unstable?

2. HISTORY

Pain / bleeding / discharge / fever / urinary / bowel / sexual / menstrual / surgical

3. EXAMINATION

General → abdomen → external genitalia → speculum → bimanual

4. DIFFERENTIAL

Think:
Gynaecological + GI + urinary + vascular

5. INVESTIGATIONS

β-hCG + CBC + U&E + CRP ± group/crossmatch + urine + TVUS

6. INITIAL MANAGEMENT

Analgesia + IV access + fluids/blood if required + antibiotics if infection + NPO if surgery possible

7. DEFINITIVE MANAGEMENT

Medical / drainage / laparoscopy / laparotomy / hysteroscopy / embolization / other specialty.

8. ESCALATE

Senior gynaecologist ± anaesthesia ± radiology ± ICU ± urology/colorectal/vascular.

9. FOLLOW-UP

Clinical response → pathology/histology → repeat imaging where indicated → definitive treatment of underlying disease.

10. DISCHARGE

Medication + warning signs + follow-up + documented safety-net + handover.
