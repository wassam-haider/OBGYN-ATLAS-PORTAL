MASTER GYNECOLOGY PROCEDURES & OPERATIVE MANOEUVRES
MRCOG / FCPS Comprehensive RCOG-first procedural atlas

Consolidated version: procedures + classifications + indications + prerequisites + instruments + technique + endpoints + observations + contraindications + complications + failure/escalation + numerical thresholds + blood-ordering principles

Scope: Gynecology only. Obstetric procedures such as caesarean section, ECV, shoulder dystocia, operative vaginal delivery and placenta accreta surgery are excluded.

Guideline hierarchy: RCOG where applicable → NICE/BSGE/BGCS/UK standards → ACOG where useful for comparison. Numerical values are labelled where they are guideline thresholds, procedure-specific thresholds, clinical reference values, or approximate textbook values. Local hospital blood-bank protocols always take precedence over a generic blood-ordering table.

PART XVI — MRCOG/FCPS PROCEDURE-MANAGEMENT PEARLS ⭐⭐⭐
1. Never learn a procedure as an isolated operation

Always connect:

INDICATION → ANATOMY → INSTRUMENT → TECHNIQUE → ENDPOINT → COMPLICATION → ESCALATION

2. The ureter is the critical structure in major pelvic surgery

Particularly remember it during:

Hysterectomy
Radical hysterectomy
Endometriosis surgery
Sacrocolpopexy/apical surgery
Ovarian surgery
Pelvic oncology
Adhesiolysis.
3. Always distinguish diagnostic from therapeutic procedures

Examples:

Diagnostic hysteroscopy → visualise/biopsy

Operative hysteroscopy → treat pathology

Diagnostic laparoscopy → inspect

Operative laparoscopy → treat

4. Histology is definitive for suspected malignancy

Visual appearance alone does not establish:

Cervical cancer
Vulval cancer
Endometrial cancer
Ovarian malignancy.
5. Endometrial thickness is context-dependent

The ≤4 mm value is principally a commonly used reassuring threshold in appropriately evaluated postmenopausal bleeding, not a universal endometrial-thickness cutoff for every woman.

6. AMH is not a pregnancy test

AMH estimates ovarian reserve/expected ovarian response.

It does not reliably determine whether spontaneous conception will occur.

7. Normal Doppler does not exclude ovarian torsion

Clinical suspicion remains paramount.

8. A negative blind endometrial biopsy does not exclude focal disease

If symptoms persist or imaging/hysteroscopy is suspicious:

further cavity assessment is required.

9. Excessive destruction during ovarian drilling can be harmful

The objective is controlled treatment, not maximal ovarian destruction.

10. Major pelvic surgery requires blood-loss planning

Especially:

Ovarian cancer debulking
Radical hysterectomy
Pelvic exenteration
Large fibroid surgery
Extensive adhesiolysis
Major endometriosis surgery.

FINAL MRCOG/FCPS MASTER FORMULA

For any gynecological procedure, answer in this order:

WHAT? → TYPES? → WHEN? → WHY? → ANATOMY? → PRE-REQUISITES? → INSTRUMENTS? → HOW? → ENDPOINT? → WHAT TO MONITOR? → CONTRAINDICATIONS? → COMPLICATIONS? → WHEN TO STOP? → WHAT NEXT? → WHAT TO DOCUMENT? → RCOG/NICE PEARL?

And whenever a numerical value appears, classify it as:

① RCOG/NICE diagnostic threshold
② Procedure-specific threshold
③ Validated classification criterion
④ Common clinical reference range
⑤ Approximate textbook value
⑥ Laboratory/assay-dependent value

This prevents the common MRCOG/FCPS error of memorising an approximate textbook number as though it were a universal RCOG diagnostic cutoff.
