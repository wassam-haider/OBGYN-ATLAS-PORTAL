The most important RCOG/NICE distinction

Don't memorise every laboratory value as a rigid “normal/abnormal” cut-off.

For exams and clinical practice, divide values into:

A. Physiological pregnancy ranges
→ Hb ↓, WBC ↑, creatinine ↓, ALP ↑, fibrinogen ↑, D-dimer ↑, albumin ↓.

B. Formal diagnostic thresholds
→ 140/90, 160/110, PCR 30, ACR 8, creatinine 90, ALT 40, platelets 150.

C. Disease-severity thresholds
→ ALT 70, bile acids 100, MCA-PSV 1.5 MoM, Hb 85, fibrinogen 2 g/L.

D. Screening thresholds
→ aneuploidy ≥1:150, RMI ≥250.

E. Assay-dependent reference values
→ TSH, FT4, ferritin, AMH, testosterone, prolactin, vitamin levels, etc. should be interpreted using the relevant laboratory/assay and clinical context.

NICE's current antenatal framework recommends booking FBC, blood group/RhD and infectious-disease/haemoglobinopathy screening, with repeat FBC and antibody testing at 28 weeks. NICE's current fertility guideline was updated in March 2026, so older MRCOG notes containing older AMH/FSH or semen reference values should be checked against the new recommendations.
