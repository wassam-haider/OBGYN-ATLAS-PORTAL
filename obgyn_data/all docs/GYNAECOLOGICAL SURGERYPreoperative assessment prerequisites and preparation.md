Z. MRCOG OSCE — THE 12-POINT PRE-OP ANSWER

If examiner says:

"How would you prepare this patient for surgery?"

Use this sequence:

1. Confirm indication
2. Confirm diagnosis
3. Discuss alternatives
4. Assess fertility wishes
5. Full medical/surgical/anaesthetic history
6. Medication + allergy review
7. Full examination
8. Review appropriate investigations/imaging/histology
9. Optimise comorbidities and anaemia
10. VTE + infection + blood-loss assessment
11. Valid consent with procedure-specific risks
12. Anaesthetic + theatre + postoperative plan
