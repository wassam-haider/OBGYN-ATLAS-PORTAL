SECTION 1

Overview & Core Guidance

A useful exam framework is:

➔ Clinical presentation → Initial/working diagnosis → Differential diagnoses → Definitive diagnosis / confirmatory test
Important
In many OBGYN conditions, there is no single “definitive test.” The diagnosis is established by a combination of history + examination + laboratory/imaging findings, with histopathology being definitive for many neoplastic conditions.

The highest-yield distinction to remember

“Initial diagnosis” is what you suspect from the presentation.

“Differential diagnosis” is what else could explain it.

“Definitive diagnosis” is the evidence that establishes the actual condition.

For example:

Pain + amenorrhoea + positive β-hCG

➔ → Initial: suspected ectopic pregnancy
➔ → Differentials: miscarriage, corpus luteum, PUL
➔ → Definitive/confirmatory: TVUS demonstrating an extrauterine gestation; operative confirmation if required.

Postmenopausal bleeding

➔ → Initial: abnormal postmenopausal bleeding
➔ → Differentials: atrophy, polyp, hyperplasia, cancer
➔ → Definitive: endometrial histopathology when endometrial pathology is suspected.

Heavy menstrual bleeding + enlarged irregular uterus

➔ → Initial: structural uterine pathology, likely fibroid
➔ → Differentials: adenomyosis, polyp, malignancy
➔ → Confirmatory: ultrasound
➔ → Definitive pathological diagnosis: histology if tissue is obtained.
