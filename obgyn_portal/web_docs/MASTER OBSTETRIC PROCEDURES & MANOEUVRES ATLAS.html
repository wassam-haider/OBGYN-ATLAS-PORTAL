Every obstetric procedure should be learned using the same framework:

2. Classification What are the types/subtypes?
3. Timing At what gestation/stage?

7. Instruments What equipment is required?
8. Technique How is it performed?
9. Endpoint What constitutes success?
10. Observation What must be monitored?
11. Contraindications When should it not be performed?
12. Complications Maternal/fetal/procedural
13. Failure When must the attempt stop?

Universal operative sequence

SECTION 6

2. NUCHAL TRANSLUCENCY

Timing

🔵 11+0–13+6 weeks

with appropriate CRL range.

Technique

➔ Mid-sagittal fetal image → fetal neck neutral → magnification → measure maximal sonolucent NT.

Increased NT

🟢 ≥3.5 mm is a commonly used high-risk threshold.

Important

NT is a screening marker, not a diagnosis.

Subsequent procedures

Depending on risk:

NIPT

CVS

amniocentesis

detailed anomaly scan

fetal echocardiography

Complications

None from ultrasound itself; downstream diagnostic procedures carry invasive-procedure risks.

SECTION 7

3. CVS

Definition

Sampling chorionic villi for genetic diagnosis.

Classification

Transabdominal CVS

Most commonly used.

Transcervical CVS

Selected circumstances/operator expertise.

Timing

🔵 ≥11+0 weeks

Avoid before 10 weeks.

Instruments

Ultrasound machine

CVS needle

Guide needle where used

Syringe

Chorionic-villus sampling system

Specimen container/media

Prerequisites

Confirm viable intrauterine pregnancy

Confirm gestational age

Determine placental position

Confirm indication

Review genetic counselling

Check maternal blood group/Rh status

Consent

Sterile preparation

Ultrasound guidance

Technique

➔ US localisation → sterile preparation → needle directed into placenta → chorionic villi aspirated → specimen assessed for adequacy → needle removed.

Endpoint

Adequate villous sample without significant maternal/fetal complication.

Advantages

Earlier diagnosis than amniocentesis.

Limitation

CVS samples placenta rather than fetal tissue directly.

Therefore:

Confined placental mosaicism can complicate interpretation.

Complications

Pregnancy loss

Bleeding

Infection

Fetomaternal haemorrhage

Mosaicism

Inadequate sample

RCOG states that when CVS/amniocentesis is performed by a skilled operator, procedure-related miscarriage risk is likely <0.5%, although risk is higher in multiple pregnancy.

Amniotomy device

Before ARM

SECTION 38

RCOG defines shoulder dystocia as vaginal cephalic birth in which additional manoeuvres are required after the head has delivered and gentle traction has failed.

SECTION 94

PART XXIV — THE THREE-LAYER MRCOG ANSWER

For any procedure in an SBA, OSCE or viva, answer in this order:

Layer 1 — Clinical

Why am I doing it?

Layer 2 — Technical

How do I safely perform it?

Layer 3 — Rescue

What do I do if it fails or causes deterioration?

For example:

ARM

➔ Indication → check presentation/station/engagement → exclude contraindication → fetal assessment → ARM → confirm FHR → watch for cord prolapse → escalate if complication.

Vacuum

➔ Indication → prerequisites → position/station → flexion point → application → traction with contractions → descent → endpoint → stop criteria → alternative birth.

Shoulder dystocia

➔ Recognise → call help → McRoberts → suprapubic pressure → internal manoeuvres → posterior arm → all-fours → rescue → neonatal/maternal assessment.

The operative rule for the entire atlas

➔ INDICATION → PREREQUISITES → ANATOMY → INSTRUMENT → TECHNIQUE → ENDPOINT → OBSERVATION → COMPLICATION → FAILURE → ESCALATION

And the most important MRCOG/FCPS principle:

Do not merely know how to perform a manoeuvre. Know when it is indicated, when it is contraindicated, what successful completion looks like, when to stop, and what the next procedure is.

This is particularly important for operative vaginal birth: RCOG emphasises competency in both vacuum and forceps for non-rotational birth, specialist rotational competence, accurate assessment of fetal head position, and stopping rather than forcing a difficult rotation.
