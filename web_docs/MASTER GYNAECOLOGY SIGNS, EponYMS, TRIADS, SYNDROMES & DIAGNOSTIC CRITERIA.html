SECTION 1

Overview & Core Guidance

Below is the single consolidated version, combining all the material above without intentionally removing the physiological signs, pathological signs, triads, eponyms, imaging signs, microscopic signs, syndromes, and diagnostic criteria.

Important
RCOG/ACOG do not have one official document containing “all gynecological signs.” This is an exam-oriented master catalogue based on their gynaecology curricula/guidance and standard diagnostic frameworks. A sign may be suggestive, whereas a diagnostic criterion or histological diagnosis may be confirmatory.

14. PID

Classic tenderness triad

Cervical motion tenderness + uterine tenderness + adnexal tenderness

Minimum clinical diagnostic approach

Pelvic/lower abdominal pain plus:

Cervical OR uterine OR adnexal tenderness

Other findings:

Fever

Abnormal discharge

Raised CRP/ESR

STI positivity

Deep dyspareunia

SECTION 72

72. THE EXAMINATION FRAMEWORK TO MEMORIZE

For any gynecological disease, think in this sequence:

➔ SYMPTOMS → PHYSICAL SIGN → Eponym/triad → FIRST-LINE INVESTIGATION → DIAGNOSTIC CRITERIA → GOLD-STANDARD/CONFIRMATORY TEST → CLASSIFICATION/STAGING

For example:

Endometriosis

➔ Dysmenorrhoea/deep dyspareunia → uterosacral tenderness/nodule → ground-glass endometrioma → TVUS → clinical/imaging diagnosis → laparoscopy/histology when required → stage/location

PCOS

➔ Oligomenorrhoea + hirsutism → hyperandrogenism → Rotterdam → exclude mimics → metabolic assessment

PID

➔ Pelvic pain → cervical motion/uterine/adnexal tenderness → STI testing + inflammatory markers/imaging as indicated → clinical diagnosis → complications assessment

Ovarian torsion

➔ Acute unilateral pain + vomiting → adnexal tenderness → enlarged ovary/whirlpool → urgent gynaecological assessment → surgery confirms torsion

Endometrial cancer

➔ Postmenopausal bleeding → abnormal endometrium → endometrial sampling → histology → staging

Highest-yield distinction

Physiological sign ≠ pathological sign ≠ diagnostic criterion ≠ gold standard.

For MRCOG/FCPS-style questions, this distinction is particularly important. For example:

➔ Strawberry cervix → strongly suggests trichomoniasis, but microbiological testing is more definitive.
➔ Chandelier sign → supports PID, but is not pathognomonic.
➔ Ground-glass ovary → suggests endometrioma.
➔ Whirlpool sign → strongly suggests torsion, but absence does not exclude it.
➔ CA125 elevation → does not diagnose ovarian cancer.
➔ Normal ultrasound → does not exclude endometriosis.
➔ Polycystic ovarian morphology → does not by itself diagnose PCOS.
➔ Postmenopausal bleeding → is a red flag requiring assessment, not itself a diagnosis.

This is the consolidated physiological + pathological gynecology signs, eponyms, triads, syndromes, imaging signs, histological signs and diagnostic-criteria master reference, with obstetrics excluded.
